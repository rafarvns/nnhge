# text — the built-in NNHGE font

Header: `<nnh/gfx.hpp>` · Spec: [005](../../specs/005-text-and-builtin-font/spec.md) · Drawing in general:
[gfx.md](gfx.md) · Debug text uses this font too: [debug.md](debug.md)

Every game has the NNHGE font: it is part of the engine (its texture is created by `nnh::init()`), so
text looks **the same, pixel for pixel, on the PC simulator, the 3DS and any future console**, and a
layout measured on PC fits on the console.

```cpp
nnh::gfx::draw_text(nnh::Screen::Top, {8, 8}, "Olá! Score: 1200");
nnh::gfx::draw_text(nnh::Screen::Top, {200, 100}, "PAUSED",
                    {.color = nnh::colors::yellow, .scale = 2, .align = nnh::TextAlign::Center, .shadow = true});

const nnh::Vec2 size = nnh::gfx::measure_text("Game Over", 2);   // {144, 20}
```

| API | |
|-----|-|
| `gfx::draw_text(screen, position, utf8, options = {})` | draws text; `position` is the top-left of the first line (for left alignment) |
| `gfx::measure_text(utf8, scale = 1)` | `{widest line, lines × 10}` × scale, in pixels; `""` → `{0, 0}` |

`TextOptions`:

| Field | Default | Effect |
|-------|---------|--------|
| `color` | white | text color |
| `scale` | 1 | 1–8, whole pixels so text stays sharp |
| `align` | `TextAlign::Left` | `Center` / `Right`: each line is centered on / ends at `position.x` |
| `shadow` | false | a drop shadow one (scaled) pixel down-right, in `shadow_color` (default `rgba(0, 0, 0, 160)`) |
| `layer` | 0 | 0–15, like sprites |
| `ignore_camera` | false | `position` in screen pixels (HUD) |

## The font

- **8×8 cells, monospace**: every character advances 8 pixels (× scale); lines are 10 pixels apart
  (`kFontCellSize`, `kFontLineHeight`). 50 characters fit in a line of the top screen, 40 on the bottom.
- **Characters**: printable ASCII and Latin-1 — Portuguese, Spanish, French, German and other Western
  languages (á ã â à ç é ê í ó õ ô ú ü ñ ß ¿ ¡ « » ° ± …). Strings are **UTF-8**. Characters the font
  doesn't have (€, emoji, CJK) and invalid UTF-8 draw a hollow box; nothing crashes or reads past the
  string.
- `\n` starts a new line; `\r` is ignored; spaces advance without drawing.
- Original to NNHGE (zlib), generated by `scripts/make_font.py` into `engine/core/src/text/builtin_font.cpp`.

## Costs

Each drawn character is one sprite in the frame's draw list (two with a shadow), so it counts against
`AppConfig::gfx.max_draws` ([gfx.md](gfx.md#capacities)) and follows layers and cameras like any sprite.
Spaces cost nothing. The font texture takes 64 KB of linear memory (tag `font`), once.

Example: [`examples/text`](../../examples/text/main.cpp).
