## Design

### Decision D21 — who mixes

The 3DS DSP mixes up to 24 channels in hardware, each with its own rate, volume per speaker and
looping. So the platform contract exposes **voices** (play a sample with these parameters, change them,
stop, is it playing) and **streams** (queue PCM buffers), and core decides everything else: which voice
plays what, priorities, group and master volume, fades, loop points, music decoding. The PC backend
implements the same voices with a small software mixer inside SDL's audio callback. Alternative
rejected: core mixes everything into one PCM stream — identical bits everywhere, but costs the Old 3DS
CPU what the DSP does for free.

### Public API (`<nnh/audio.hpp>`)

```cpp
namespace nnh {
enum class AudioGroup : std::uint8_t { Effects, Music, Dialogue };

class Sound {                          // move-only, like Texture; decoded PCM in Linear memory
public:
    bool valid() const; float duration() const; /* seconds */ void reset();
};
Result<Sound> load_sound(const char* path);   // "sfx/jump" -> assets sfx/jump.wav or sfx/jump.ogg

struct Voice { std::uint16_t slot = 0, generation = 0; };      // a playing instance; stale = harmless

struct PlayOptions {
    float volume = 1.0f;      // 0..1
    float pan = 0.0f;         // -1 left .. +1 right
    float pitch = 1.0f;       // 0.25..4, changes speed too
    bool loop = false;
    AudioGroup group = AudioGroup::Effects;
    std::uint8_t priority = 128;   // higher wins when voices run out
};

namespace audio {
Voice play(const Sound& sound, const PlayOptions& options = {});   // {} voice if dropped
void stop(Voice v);
void set_paused(Voice v, bool paused);
void set_volume(Voice v, float volume);
void set_pan(Voice v, float pan);
void set_pitch(Voice v, float pitch);
bool playing(Voice v);

void set_volume(AudioGroup g, float volume);     // and master:
void set_master_volume(float volume);
float volume(AudioGroup g);
void set_paused(AudioGroup g, bool paused);      // e.g. pause menu: effects + dialogue
bool available();                                // false = running silently (reason logged once)
} // namespace audio

namespace music {
struct Options {
    bool loop = true;
    std::uint32_t loop_start = 0;   // in samples (frames); 0 = the file's LOOPSTART tag, else the start
    float volume = 1.0f;
    float fade_in = 0.0f;           // seconds
};
Result<void> play(const char* path, const Options& options = {});      // replaces the current track
Result<void> crossfade(const char* path, float seconds, const Options& options = {});
void stop(float fade_out = 0.0f);
void set_paused(bool paused);
void set_volume(float volume);
bool playing();
float position();                  // seconds into the track
} // namespace music
} // namespace nnh
```

`AppConfig` gets `AudioConfig audio = {}` with `.voices = 16` (1–22). Errors: `NotFound` (no such asset,
"did you mean" from spec 007), `InvalidArgument` (bad path), `Unsupported` (format: e.g. 24-bit WAV,
more than 2 channels, rate outside 8–48 kHz), `Corrupted` (broken file), `OutOfMemory`, `LimitReached`
(too many sounds loaded: `AudioConfig::max_sounds`, default 128).

### Events introduced

| Event | Published by | Payload | Typical listeners |
|-------|--------------|---------|-------------------|
| `SoundFinished` | audio, in `frame()` | `Voice voice` | game code chaining effects; not sent for `stop()` |
| `MusicFinished` | audio, in `frame()` | — | scenes changing track after a jingle |

### Readers (pure core logic, `core/src/audio/`)

- `wav_reader` — RIFF/WAVE, `fmt ` PCM 8/16-bit, 1–2 channels, 8–48 kHz; skips unknown chunks; every
  size and offset bounds-checked against the file; returns a view (format + data range), no copy.
- `ogg_reader` — wraps stb_vorbis (vendored in `third_party/stb_vorbis/`, compiled as one C file with
  warnings off and `STB_VORBIS_NO_STDIO`, `STB_VORBIS_NO_PULLDATA_API`): the **push-data** API, fed by
  core from the asset in 4 KB reads. Reads `LOOPSTART` from the comments. For a loop point, the first
  pass remembers the file offset of the Ogg page that contains it; looping seeks there, flushes the
  decoder and drops samples up to the loop point (no re-decoding of the intro). Its scratch memory comes
  from a fixed arena (tag `audio`), not `malloc`.
- Effects (WAV or OGG) are decoded whole to 16-bit PCM at load time, then handed to the platform.
  Music may also be WAV (streamed, no decoding).

### Mixer state (core, `core/src/audio/`)

- `voices` — the voice table: `{slot, generation}` handles, priority + start order for stealing (lowest
  priority, then oldest; a new sound below every busy priority is dropped and logged once per sound).
- `mixer` — group and master volumes, group pause, fades (linear, advanced once per `frame()` by the
  frame's delta), final per-speaker gains from volume × group × master and pan (constant-power).
- `music` — the streaming state machine: two music slots (crossfade), each with a decoder, a read
  position in the asset and loop state. In `frame()`, core tops up the platform's free stream buffers
  (4 buffers × 4096 frames each, ≈ 0.5 s queued at 32 kHz), then publishes the events.
- Polling: once per frame core asks the platform whether its playing voices are still playing; ended
  non-looping voices free their slot and publish `SoundFinished`.

### Platform contract (`nnh/platform/audio.hpp`, plus streaming reads in `assets.hpp`)

```cpp
bool audio_init(int voices, int streams);            // false = no audio device / no DSP firmware
void audio_shutdown();
// Sample memory belongs to the platform (3DS: linearAlloc + cache flush; PC: heap), like textures.
bool sample_create(const std::int16_t* frames, std::uint32_t count, int channels, std::uint32_t& id);
void sample_destroy(std::uint32_t id);
struct VoiceParams { float gain_left, gain_right, rate; };      // rate = sample rate × pitch
void voice_start(int voice, std::uint32_t sample, int sample_rate, bool loop, const VoiceParams& p);
void voice_update(int voice, const VoiceParams& p);
void voice_pause(int voice, bool paused);
void voice_stop(int voice);
bool voice_playing(int voice);
// Streams: fixed buffers owned by the platform.
bool stream_start(int stream, int channels, int sample_rate);
std::int16_t* stream_free_buffer(int stream, std::uint32_t& capacity_frames);   // nullptr = all queued
void stream_submit(int stream, std::uint32_t frames);
void stream_update(int stream, const VoiceParams& p);
void stream_pause(int stream, bool paused);
void stream_stop(int stream);
// assets.hpp, for music:
bool asset_open(const char* path, std::uint32_t& handle);
bool asset_read_at(std::uint32_t handle, std::uint64_t offset, void* buffer, std::size_t size, std::size_t& read);
void asset_close(std::uint32_t handle);
```

- **3ds** (`audio_3ds.cpp`): `ndspInit()` (fails without `sdmc:/3ds/dspfirm.cdc` → `false`); voices map
  to ndsp channels 0..N-1, streams to channels 22–23; `ndspChnSetRate`, `ndspChnSetMix`, `ndspWaveBuf`
  with `looping`; stream buffers in `linearAlloc`, `DSP_FlushDataCache` before queueing. Suspend and
  sleep: libctru's ndsp pauses the DSP through its APT hook while `frame()` is blocked in
  `aptMainLoop()`; verified on hardware (AC-3), with an explicit pause in our own APT hook if needed.
  `asset_open` = `fopen("romfs:/…")`.
- **pc** (`audio_pc.cpp` + `audio_mixer_pc.cpp`): one `SDL_AudioStream` (stereo, float, 48 kHz) fed by a
  callback that mixes the voices and streams with linear resampling and per-voice gains interpolated over
  each callback block (no zipper noise). Commands reach the callback under `SDL_LockAudioStream`. No
  device → `audio_init` returns false. `asset_open` = `SDL_IOFromFile`.
- **fake**: records every command (voices started, params, buffers submitted, pauses); tests set
  "voice N finished" and "audio unavailable"; in-memory asset streams.

### Build (`cmake/nnh_assets.cmake`)

`.wav` and `.ogg` files in the assets folder go through `cmake/nnh_check_sound.cmake` (header only:
WAV PCM 8/16-bit, 1–2 channels, 8–48 kHz; OGG magic `OggS` + Vorbis identification header, channels and
rate), so a bad file fails the build naming it; then they are copied unchanged. Same step on PC and 3DS.

### Example `examples/audio`

`make_sounds.py` synthesizes original sounds (effects: jump, coin, hit; two short music loops with an
intro) into `assets/`. Music as OGG needs a Vorbis encoder once: `pip install soundfile` (libsndfile
includes Vorbis) on the maintainer's machine; the generated `.ogg` files are committed, so building the
example needs nothing. The screen shows the groups' volumes (D-Pad), A/B/X/Y play effects (several
overlapping), L/R crossfade between tracks, SELECT pauses the effects group, START exits.

### Data and memory (Old 3DS)

- Voices: 22 × ~32 B; sounds table 128 × ~24 B; core heap < 8 KB.
- Stream buffers: 2 streams × 4 × 4096 frames × 2 ch × 2 B = 128 KB `Linear`.
- stb_vorbis per decoder: ~100–200 KB (measured; reported under `audio`), 2 decoders during a crossfade.
- Effects: decoded PCM in `Linear` (1 s mono at 32 kHz = 64 KB), counted under `audio`.
- Music decoding target: ≤ 15 % of a frame on an Old 3DS for 32 kHz stereo (AC-4, debug overlay).

## Risks and alternatives

- **stb_vorbis CPU on the Old 3DS** — not measured yet. If music decoding exceeds the budget: lower the
  music rate (22 kHz), or swap the decoder for Tremor (BSD) or build-time DSP-ADPCM behind the same API
  (spec open question 1).
- **stb_vorbis robustness** — it has had fuzzing bugs in the past; we pin a version, fuzz it ourselves,
  and assets come from the game's own build (not downloaded), which limits exposure.
- **Main-thread streaming** — a load longer than ~0.5 s (e.g. many textures) can starve the music. The
  example loads at start; if games hit it, a later step moves feeding to a thread (ndsp callback / SDL
  thread) behind the same contract.
- **Volume steps once per frame on 3DS** may click on fast fades; mitigation: shorter steps via the
  ndsp callback later, or accept (fades are ≥ 0.1 s).
- **Example OGG files** need `soundfile` once on the maintainer's machine; fallback: WAV music.
