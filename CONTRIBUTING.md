# Contributing

Thanks for helping! The short version:

1. Pick an item from [docs/ROADMAP.md](docs/ROADMAP.md) (or open an issue first for new ideas).
2. A change is done when it **works on the PC simulator and on 3DS**, has **docs** (header comments +
   `docs/api/`) and an **example** or test.
3. Don't slow the build down: keep public headers light, no heavy dependencies. Budgets are in
   [CLAUDE.md](CLAUDE.md#build-speed).
4. Format with `.clang-format`. Code and docs in English.
5. Never submit Nintendo SDK code, leaked material or copyrighted assets.

By contributing, you agree your work is released under the [zlib license](LICENSE).
